# Portfólio Jean Almeida

Portfólio pessoal de Jean Almeida, desenvolvido para apresentar sua trajetória, seus projetos e seu trabalho com desenvolvimento frontend, design de interfaces e experiências digitais.

![Preview do portfólio](projeto2.png)

## Sobre o projeto

O site reúne três áreas principais:

- **Sobre**: apresentação pessoal e trajetória acadêmica.
- **Projetos**: carrossel com projetos carregados dinamicamente a partir de `config.js`.
- **Contato**: links para GitHub e Instagram, chamada para contato e informações de copyright.

## Funcionalidades

- Layout responsivo para desktop, tablet e mobile.
- Menu de navegação adaptado para telas menores.
- Carrossel de projetos com autoplay, navegação por botões, teclado, indicadores e arraste com o mouse ou toque.
- Animações de entrada, efeitos de parallax e elementos visuais em movimento.
- Botão de voltar ao topo com indicador de progresso da página.
- Suporte a `prefers-reduced-motion` para reduzir animações quando essa preferência está ativa.
- Links externos para GitHub e Instagram.

## Tecnologias

- HTML5 semântico
- CSS3, variáveis CSS, Flexbox e Grid
- JavaScript moderno para DOM e interações
- Font Awesome para os ícones
- Google Fonts com a família Poppins

## Estrutura do projeto

- `index.html`: estrutura das seções Sobre, Projetos e Contato.
- `styles.css`: layout, responsividade, animações e identidade visual.
- `script.js`: menu mobile, carrossel, parallax, links e progresso de rolagem.
- `config.js`: dados dos cursos e projetos exibidos no site.
- `profile.webp`: imagem de perfil.
- `projeto1.png` e `projeto2.png`: imagens dos projetos apresentados.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/jeandevzinweb/portifolio.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd portifolio
   ```

3. Abra `index.html` diretamente no navegador ou use a extensão Live Server no VS Code para iniciar um servidor local.
